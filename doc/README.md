# Nhật ký dự án

Tóm tắt công việc theo ngày và theo tuần, dùng cho báo cáo hàng tuần và báo cáo cuối kỳ.

| Thư mục | Nội dung |
|---|---|
| `nhat-ky/` | Mỗi ngày làm việc một tệp `YYYY-MM-DD.md`: đã làm gì, kết quả chính, việc tiếp theo |
| `tuan/` | Tổng kết mỗi tuần `tuan-NN.md`: sản phẩm chạy được, số liệu, so với tuần trước |
